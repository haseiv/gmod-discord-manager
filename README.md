# Discord-бот для Garry's Mod

Бот включает настраиваемые тикеты, сбор статистики игровых серверов, отчёты администрации, отправку сообщений от имени бота и базовую защиту Discord-сервера. Данные сохраняются атомарно в `data/database.json`.

## Возможности

- Панель тикетов с пунктами «Амнистия», «Жалоба» и «Заявка на хелпера».
- После каждого выбора в панели тикетов исходное сообщение обновляется, а меню сбрасывается для следующего обращения.
- Для каждого типа настраиваются название, описание, emoji, категория, роль поддержки и состояние.
- Приватный канал тикета, кнопки «Взять» и «Закрыть», текстовый транскрипт в журнале.
- Защищённый HTTP API для денег, игрового времени, убийств и онлайна нескольких GMod-серверов.
- Отчёт администрации через Discord-форму с кнопками принятия и отклонения.
- Команда отправки сообщения от имени бота.
- Временные личные войсы: создание при входе в лобби и панель владельца.
- Антирейд, антиспам/массовые упоминания и антинюк по журналу аудита.

## Требования

- Node.js 22 LTS (минимум 20).
- Discord-приложение и бот на [Developer Portal](https://discord.com/developers/applications).
- В разделе **Bot → Privileged Gateway Intents** включить `Server Members Intent` и `Message Content Intent`.
- Роль бота должна находиться выше ролей, которые защита может снять.

Рекомендуемые права бота: View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Manage Channels, Move Members, Manage Roles, Moderate Members, Kick Members, View Audit Log. Право Administrator не требуется.

## Быстрый запуск

### Bothost

В настройках существующего бота откройте «Дополнительные настройки», включите **«Использовать собственный Dockerfile»** и выберите `Dockerfile` из этого репозитория. Ветка Git: `main`. После сохранения запустите **новый деплой**: обычный рестарт не пересобирает образ. Dockerfile запускает Node.js 22 и файл `dist/index.js`.

Если в настройках доступен выбор языка, укажите **Node.js**. Не указывайте `src/api.ts` в поле «Главный файл»: этот TypeScript-файл нельзя запускать Python. При использовании собственного Dockerfile запуск определяется инструкцией `CMD`, поэтому поле «Главный файл» можно оставить пустым.

В переменных среды Bothost задайте `DISCORD_TOKEN` (или `BOT_TOKEN`, который Bothost может передать автоматически). Slash-команды регистрируются автоматически на всех серверах бота при запуске и при добавлении бота на новый сервер; `DISCORD_CLIENT_ID` нужен только для ручного `npm run deploy`. `GMOD_API_SECRET` — ваш общий секрет для бота и Lua-модуля (не менее 24 символов); без него бот запускается, но API игровой статистики отключён. `DISCORD_GUILD_ID` используется только при ручном `npm run deploy`. Для HTTP API порт можно задать через `HTTP_PORT`; если он не указан, используется переменная `PORT` от Bothost, затем 3000.

Выберите для приложения **Node.js 22**, а не Python. Главный файл после сборки — `dist/index.js`; файлы `src/*.ts` нельзя запускать через Python. В панели хостинга укажите:

```text
Build: npm ci && npm run build
Start: npm start
```

Команды Discord регистрируются отдельно: `npm run deploy` (после заполнения переменных окружения). Если хостинг поддерживает Docker, используйте `Dockerfile` или `compose.yml`: в образе уже указан запуск через Node.js.

```powershell
Copy-Item .env.example .env
npm install
npm run deploy
npm run build
npm start
```

Заполните `.env` до запуска. `GMOD_API_SECRET` должен быть случайной строкой минимум из 24 символов. Для генерации в PowerShell:

```powershell
[Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
```

Если указан `DISCORD_GUILD_ID`, команды появятся на тестовом сервере почти сразу. Без него регистрируются глобальные команды, их обновление может занять время.

Для Docker:

```powershell
docker compose up -d --build
docker compose logs -f bot
```

## Первичная настройка в Discord

Если сервер ещё не оформлен, администратор может выполнить `/server setup`. Команда создаёт шаблон DarkRP по категориям (информация, общение, форум, личные комнаты, торговля, набор, администрация), текстовые и голосовые каналы и базовые роли. Уже существующие элементы с теми же названиями в соответствующих категориях повторно не создаются; ничего не удаляется. Административная категория скрыта от обычных участников. Боту нужны права Manage Channels и Manage Roles. Команда также подключает созданный войс «Создать комнату» к системе временных комнат. Панели публикуются отдельно через `/panel deploy`.

1. `/tickets type` — настройте каждый тип обращения, его категорию и роль поддержки.
2. `/tickets logs` — выберите канал архива.
3. `/panel deploy panel:Тикеты` — опубликуйте панель тикетов в нужном канале.
4. `/reports setup` — укажите канал отчётов и роль проверяющих.
5. `/security setup` — выберите канал тревог и пороги защиты.
6. `/voice setup` — подтвердите канал создания войсов и при необходимости выберите категорию.
7. `/panel deploy panel:Кастомные войсы` — опубликуйте панель управления войсами.

Остальные команды:

- `/tickets close` — закрыть текущий тикет.
- `/reports submit` — подать отчёт.
- `/say text` — обычное сообщение от имени бота.
- `/say embed` — эмбед с заголовком, текстом и цветом.
- `/say staff` — эмбед состава по одной–пяти ролям; список участников обновляется автоматически при выдаче/снятии ролей и после перезапуска бота. Например, выберите роль «Специальный админ», и под её названием появятся упоминания всех участников с этой ролью.
- `/stats player` — статистика по SteamID64.
- `/stats server` — онлайн всех подключённых серверов.
- `/security status` — текущие параметры защиты.

## Кастомные голосовые каналы

Канал `1544411530148184209` установлен как канал создания по умолчанию. Рекомендуется явно выполнить настройку после приглашения бота:

```text
/voice setup lobby:#Создать-войс category:Личные-войсы
/panel deploy panel:Кастомные-войсы channel:#управление-войсом
```

Когда пользователь заходит в лобби, бот создаёт канал `🔊 Имя`, переносит пользователя и назначает его владельцем. Через опубликованную панель владелец может:

- переименовать канал;
- поставить или снять лимит участников;
- закрыть или открыть вход;
- скрыть или показать канал;
- отключить выбранного участника;
- удалить свой войс.

Пустой временный канал удаляется автоматически. Если владелец вышел, а участники остались, владение передаётся следующему участнику.

## Общая команда панелей

Все панели публикуются одной командой:

```text
/panel deploy panel:<тип панели> channel:<текстовый канал>
```

В поле `panel` Discord покажет список доступных вариантов:

- `Тикеты`;
- `Кастомные войсы`.

Отдельных команд публикации у модулей нет. При добавлении следующих панелей они также появятся в этом списке.

## Подключение Garry's Mod

Скопируйте папку `gmod/addons/discord_bridge` в `garrysmod/addons/` на игровом сервере. Добавьте в `server.cfg`:

```cfg
discord_bridge_url "http://IP_БОТА:3000/api/v1/stats"
discord_bridge_secret "ТОТ_ЖЕ_СЕКРЕТ_ИЗ_ENV"
discord_bridge_server_id "darkrp-1"
discord_bridge_server_name "DarkRP #1"
discord_bridge_interval "60"
```

Порт 3000 должен быть доступен игровому серверу. Для публичного интернета используйте HTTPS через reverse proxy и firewall, разрешающий IP игровых серверов. Никогда не публикуйте `.env` и `server.cfg`.

Скрипт по умолчанию читает деньги из DarkRP, убийства из `Frags()`, а время из `NWInt("TotalUTime")` системы UTime. Для другой системы времени измените значение через hook:

```lua
hook.Add("DiscordBotCollectPlayerStats", "MyPlaytime", function(ply, row)
    row.playtimeMinutes = math.floor(MyPlaytime.GetSeconds(ply) / 60)
end)
```

API принимает только `POST /api/v1/stats` с `Authorization: Bearer <secret>`. Проверка состояния: `GET /health`.

## Как работает защита

- Антирейд считает входы за 15 секунд. После порога новые аккаунты младше настроенного возраста автоматически исключаются.
- Антиспам удаляет сообщение и выдаёт timeout на 10 минут при 7 сообщениях за 5 секунд или 6 массовых упоминаниях.
- Антинюк считает удаления каналов/ролей, баны, кики, создание webhook и добавление ботов. После порога снимает с исполнителя доступные боту роли с опасными правами.
- Владелец сервера и сам бот не подвергаются автоматическим санкциям.

Защита снижает ущерб, но не заменяет 2FA для модераторов, минимальные права ролей, резервные копии и безопасное хранение токена.
